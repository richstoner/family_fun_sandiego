# family_fun_sandiego

Public page for SD Toddler Outings. Scheduled runs refresh it by following
`.claude/skills/sd-family-events/SKILL.md` (daily or weekly mode). Read that file in full before a run.

- `index.html`: static page that reads `events.json`. Don't edit during a scheduled run.
- `events.json`: generated by `export.py` from the private board's database. Never hand-edit.
- `export.py`: `python3 -I export.py <dir-of-event-json> <lastRun ISO> <mode>`.
